# Node.js Process

This folder contains notes and learning material about the Node.js `process` object.

The `process` object provides information about the currently running Node.js process and provides methods for interacting with and controlling it.

---

## Purpose

* Understand the Node.js `process` object
* Learn `process.argv`
* Learn `process.env`
* Learn `process.cwd()`
* Learn `process.exit()`
* Understand command-line arguments
* Understand environment variables
