# Node.js Event-Driven Architecture

This folder contains notes and learning material about event driven architecture in Node.js.

Event-driven architecture allows a program to perform specific actions when events occur.

---

## Purpose

* Understand event-driven architecture
* Understand what an event is
* Understand event handlers
* Learn how Node.js responds to events
* Understand the difference between events and event handlers
* Build a strong foundation for Node.js backend development
