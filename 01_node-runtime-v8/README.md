# Node.js Runtime & V8

This folder contains notes and learning material about the Node.js runtime environment and the V8 JavaScript engine.

Node.js allows JavaScript to run outside the browser and is commonly used for backend and server side development.

---

## Purpose

* Understand the Node.js runtime environment
* Understand the V8 JavaScript engine
* Learn the relationship between Node.js and V8
* Understand JavaScript execution in Node.js
* Learn the difference between browser and Node.js environments
* Understand browser APIs vs Node.js APIs
* Learn basic Node.js built-in APIs
* Build a strong foundation for Node.js backend development
