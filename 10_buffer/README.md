# Node.js Buffer

This folder contains notes and learning material about Node.js `Buffer`.

Buffer is used to work with binary or raw data such as files, images, videos, and network data.

---

## Purpose

* Understand Node.js Buffer
* Learn `Buffer.from()`
* Learn `Buffer.alloc()`
* Learn `buffer.toString()`
* Learn `buffer.length`
* Understand binary and raw data
* Practice Base64 encoding and decoding
