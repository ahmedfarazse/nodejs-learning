# Node.js Environment Variables

This folder contains notes and learning material about Node.js environment variables.

Environment variables are commonly used to store application configuration and sensitive values outside the main source code.

---

## Purpose

* Understand environment variables
* Learn `process.env`
* Learn `.env` files
* Practice loading `.env` with Node.js
* Understand configuration vs sensitive values
* Learn why `.env` should be added to `.gitignore`
