# Node.js Events

This folder contains notes and learning material about the Node.js `events` module.

The `events` module provides `EventEmitter`, which allows applications to create, listen for, and trigger events.

---

## Purpose

* Understand the Node.js `events` module
* Learn `EventEmitter`
* Practice event listeners with `on()`
* Practice triggering events with `emit()`
* Learn how to pass data with events
* Learn how to pass multiple arguments
* Understand `once()`
* Understand the difference between `on()` and `once()`
