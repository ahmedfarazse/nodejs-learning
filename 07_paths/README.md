# Node.js Path Module

This folder contains notes and learning material about the Node.js `path` module.

The `path` module is a built-in Node.js module used to work with file and directory paths.

---

## Purpose

* Understand the Node.js `path` module
* Learn `path.join()`
* Learn `path.basename()`
* Learn `path.dirname()`
* Learn `path.extname()`
* Learn `path.parse()`
