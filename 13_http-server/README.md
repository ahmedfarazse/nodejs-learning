# Node.js HTTP Server

This folder contains notes and learning material about creating HTTP servers using Node.js's built-in `http` module.

The examples cover basic servers, requests, responses, routing, status codes, headers, and JSON responses.

---

## Purpose

* Understand the Node.js `http` module
* Create a basic HTTP server
* Understand requests and responses
* Practice `req.url` and `req.method`
* Learn basic routing
* Understand HTTP status codes
* Learn response headers and `Content-Type`
* Send JSON responses
* Practice `JSON.stringify()`
* Understand `server.listen()`
