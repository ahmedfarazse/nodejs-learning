# Node.js File System (fs)

This folder contains notes and learning material about the Node.js File System (`fs`) module.

The `fs` module is a built-in Node.js module used to work with files and directories.

---

## Purpose

* Understand the Node.js `fs` module
* Learn how to create and write files
* Learn how to read file content
* Learn how to append content
* Learn how to rename files
* Learn how to delete files
* Understand asynchronous file operations
* Understand synchronous file operations
* Practice common `fs` methods
