# Node.js npm

This folder contains notes and learning material about npm (Node Package Manager).

npm is used to install and manage packages and dependencies in Node.js projects.

---

## Purpose

* Understand npm
* Learn `package.json`
* Practice `npm init`
* Practice installing and uninstalling packages
* Understand `node_modules`
* Understand `package-lock.json`
* Understand dependencies and devDependencies
* Learn basic npm commands
