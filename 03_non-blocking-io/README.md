# Node.js Non-Blocking I/O

This folder contains notes and learning material about non-blocking I/O in Node.js.

Non-blocking I/O allows Node.js to continue performing other work while waiting for I/O operations to complete.

---

## Purpose

* Understand I/O
* Understand blocking I/O
* Understand non-blocking I/O
* Learn the difference between blocking and non-blocking I/O
* Understand why non-blocking I/O is important in Node.js
* Understand the relationship between non-blocking I/O and event-driven architecture
