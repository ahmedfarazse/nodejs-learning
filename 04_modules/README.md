# Node.js Modules

This folder contains notes and learning material about modules in Node.js.

Modules help organize application code into separate files and allow functionality to be reused across an application.

---

## Purpose

* Understand Node.js modules
* Learn built-in, local, and third-party modules
* Understand CommonJS
* Understand ES Modules
* Practice `require()` and `module.exports`
* Practice `import` and `export`
* Understand the difference between module types and module systems
