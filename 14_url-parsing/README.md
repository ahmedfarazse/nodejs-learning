# Node.js URL Parsing

This folder contains notes and learning material about URL parsing in Node.js.

URL parsing is used to identify the path and query parameters from a URL and work with them inside an application.

---

## Purpose

* Understand URL parsing
* Learn the Node.js `url` module
* Learn the `URL` class
* Understand `pathname`
* Understand query parameters
* Practice `searchParams.get()`
* Parse URLs received through HTTP requests
