# Node.js Streams

This folder contains notes and learning material about Node.js Streams.

Streams allow data to be processed in smaller chunks instead of loading the complete data into memory at once.

---

## Purpose

* Understand Node.js Streams
* Learn Readable Streams
* Learn Writable Streams
* Understand Duplex Streams
* Understand Transform Streams
* Learn about data chunks
* Practice `createReadStream()`
* Practice `createWriteStream()`
* Practice `pipe()`
* Understand `data` and `end` events
